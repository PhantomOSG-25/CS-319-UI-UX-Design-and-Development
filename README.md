# CS 319 — Smart-Home UX Case Study

This portfolio case study documents a mobile smart-home prototype from research through interaction design. It demonstrates user-centered discovery, information prioritization, low-fidelity wireframing, visual-system decisions, and a coherent set of device-management screens.

## What this demonstrates

- Turning interview themes into interface priorities
- Designing for location, camera, communication, and smart-plug tasks
- Organizing a mobile dashboard around frequent actions
- Using progressive disclosure to keep device controls understandable
- Applying visual hierarchy, motion, and feedback intentionally
- Communicating design decisions with annotated prototype evidence
